==================================================
三、本轮核心目标
==================================================

本轮不要再学习：

Y(s,a)

而是学习：

A_B(s,a) = Y(s,a) - Y(s,a_B)

其中：

a_B = 当前 Lattice+SAC Baseline 的真实物理首动作。

Y(s,a) 定义严格保持上一阶段：

Y(s,a)
=
actual_first_reward
+
gamma * actual continuation return

其中：

gamma = 0.995

continuation policy：

冻结的原始 Lattice+SAC

终止：

原生 MetaDrive done

禁止改变 Reward、Cost、gamma、done 或成功判定。

==================================================
四、Baseline-relative target
==================================================

对于每个 origin：

首先找到唯一 Baseline candidate：

a_B

以及：

Y_B

对每个候选 i：

delta_a_i = a_i - a_B

delta_Y_i = Y_i - Y_B

训练目标：

delta_Y_i

因此：

Baseline：

delta_a_B = [0,0]

delta_Y_B = 0

所有候选收益均相对于同一起点 Baseline 计算。

禁止：

- 跨origin计算baseline
- 使用全局平均baseline
- 使用scene平均baseline
- 使用预测score构造baseline
- 使用oracle candidate构造baseline

必须严格使用同一origin的真实 Baseline。

==================================================
六、Baseline-centered advantage head
==================================================

不要简单训练一个绝对Return MLP。

实现：

raw_adv(s, delta_a) = f_theta(s, delta_a)

最终：

A_hat(s, delta_a)
=
f_theta(s, delta_a)
-
f_theta(s, 0)

这样天然满足：

A_hat(s, 0) = 0

即：

A_hat(Baseline) = 0

模型最终只负责判断：

candidate 相对于 Baseline 的收益。

不要再让模型承担 state-value 的绝对尺度学习。

八、训练目标
==================================================

训练两个目标：

--------------------------------
1. Relative regression
--------------------------------

预测：

A_hat_i

目标：

delta_Y_i

使用：

SmoothL1 / Huber

但 target normalization 必须：

只使用 fit split。

禁止使用 inner-stop 或 validation 的统计量。

--------------------------------
2. Within-origin ranking
--------------------------------

对于：

delta_Y_i > delta_Y_j

要求：

A_hat_i > A_hat_j

只在同一个 origin 内构造 Pair。

不得跨origin构造Pair。

近似平局：

abs(delta_Y_i - delta_Y_j) <= 1

继续沿用上一阶段定义。

这些Pair：

不参与主方向accuracy。

可以作为tie diagnostics。

--------------------------------
3. Loss
--------------------------------

总损失：

L = L_relative_regression + lambda_rank * L_pairwise

lambda_rank 必须在实验开始前固定。

建议：

lambda_rank = 0.25

Pairwise ranking 使用归一化后的 delta_Y。

不要再使用上一阶段：

raw_difference / 10

这种与收益尺度绑定的写法。

归一化scale：

只由fit split计算。
